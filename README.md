# Pokémon Games

A collection of Pokémon-themed mini-games built with Ruby on Rails 7 and Hotwire.

---

## Description

This project showcases **Rails 7**'s full-stack capabilities, using **Hotwire** (Turbo/Stimulus) for fast, SPA-like interactions. The frontend is styled with **Tailwind CSS** and **DaisyUI**. It uses the **HTTPX** gem to fetch Pokémon data from the PokéAPI, delivering fun and interactive browser games.

---

## Getting Started

### Dependencies

* **Ruby** (3.1+)
* **Rails** (7.0+)

### Installing

1.  **Clone the repository:**
    ```bash
    gh repo clone Gazwai/pokemon-ruby-games
    cd pokemon-ruby-games
    ```
2.  **Install dependencies:**
    ```bash
    bundle install
    ```

### Executing program

1.  **Start the server:**
    ```bash
    rails s
    ```
2.  **Open browser:**
    ```
    http://localhost:3000
    ```
